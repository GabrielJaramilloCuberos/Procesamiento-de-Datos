# **Taller de comparativa:** CSV, ORC, Parquet

En este taller, se muestra una evaluación de rendimiento para la creación de dataframes en PySpark usando archivos en formatos 'CSV', 'ORC' y 'Parquet'.

- **Dataset:** customers-2000000.csv
- **Origen:** https://www.datablist.com/learn/csv/download-sample-csv-files
- **Registros:** 2 millones
- **Tamaño:** 333 MB
